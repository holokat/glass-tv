# Navigation sounds

Glass TV bundles five short UI SFX focus cues, selected as alternatives for launcher navigation. Audio is CC0-1.0 by Yuki Capital; no UI SFX runtime is included. See LICENSE-AUDIO.txt and provenance.json for the exact upstream revision, paths and hashes.

| Glass TV choice | UI SFX pack | Cue |
| --- | --- | --- |
| Soft | soft | focus |
| Glass | glass | focus |
| Wood | organic | focus |
| Bubble | rubber | focus |
| Chime | zen | focus |

Source: https://github.com/romainsimon/uisfx

The Mac uses AVAudioPlayer for explicit previews. Android uses SoundPool for actual navigation focus changes. Sound defaults to Off, with a saved 25% effect-volume default when enabled. These are locally bundled effects, not generated through ElevenLabs. SoundCN Click Soft was reviewed as an alternative and is not distributed.
