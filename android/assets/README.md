# Bundled artwork

`wallpaper.jpg` is generated landscape artwork derived from the supplied visual reference. It is included only as Glass TV's initial empty-rotation background and does not depict a verified real location.

`weather-artwork/` contains the eight bundled AI-generated destination-artwork images used only by
scenic weather cards. They are destination illustrations, not live weather imagery. Artwork selection
requires the verified city ID or normalized city name together with a tight coordinate radius; other
locations retain the bundled neutral wallpaper. The source prompts and provenance are bundled beside
the images in `weather-artwork/provenance.json`.
