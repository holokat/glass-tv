Privacy policy

Effective 21 October 2026

Glass TV is published by 21 Media LLC, based in the United States. This policy covers the Glass TV Android TV app, the Mac companion, and this website.

What Glass TV stores on your devices

The Android app stores the information it needs to run on your TV. This can include paired-TV information, playlist and launcher settings, selected inputs, weather locations and cached forecasts, radio favorites and recent stations, uploaded ambient photos or videos, and movie catalog and poster data.

The Mac companion can store its settings, local library information, media previews, derived video files, and a reference to the folder you select for your library. Pairing credentials are stored in the macOS Keychain.

Some stored Android data can remain after you remove items from a playlist. Clearing the app’s Storage in Android settings or uninstalling the app removes Android app data. Android documents that app-specific files are removed when an app is uninstalled. Device menus vary by manufacturer. See Android’s storage guidance and app-specific storage documentation.

Mac companion files, the selected-library reference, and pairing credentials can remain on your Mac until removed.

Local TV connection

Glass TV can connect to the Mac companion over your local network. The companion sends the TV information needed for the feature, such as selected media, media names and bytes, playlist settings, weather settings, app and layout choices, and movie-library details. Movie playback can stream the selected file from the paired Mac to the TV.

The Android and Mac apps use TLS for this local connection. The Android receiver stores a hash of its bearer token instead of the token in plaintext. The Mac companion stores its pairing credential in the macOS Keychain.

Optional internet features

Weather. Searching for a city sends the search text to Open-Meteo. Loading a forecast sends the selected latitude, longitude, temperature unit, timezone setting, and forecast fields to Open-Meteo. Open-Meteo also receives the request’s IP address and connection details. Open-Meteo describes its own handling in its Terms & Privacy.

Radio. Starting a station connects your device to that station’s stream host. Loading station artwork connects to the host named by the selected station. The Android app can also recheck a selected station through Radio Browser. The website can play radio from third-party stream hosts. Those providers receive the request’s IP address and connection details and handle requests under their own terms and privacy notices.

Mac movie metadata. If you choose metadata lookup, the Mac companion sends a movie title and optional year derived from the selected local file name to Wikidata. If a matching IMDb identifier is available, it can request movie metadata from Cinemeta and download artwork from the host returned for that movie. These services also receive the request’s IP address and connection details. The app does not send the file path, movie bytes, TV credential, or pairing data to those services.

Website analytics and links

This website uses Cloudflare Web Analytics. Cloudflare describes it as real-user monitoring for page views and performance, including Core Web Vitals. Its published dimensions include page path, referrer, visitor country, device type, browser, operating system, and navigation type. Cloudflare receives connection information for website requests. Cloudflare says Web Analytics does not use cookies or localStorage for usage metrics and does not fingerprint individuals. Read Cloudflare’s Web Analytics documentation and Privacy Policy.

The Glass TV Android app and Mac companion do not use an analytics or crash-reporting SDK. The website links to GitHub for source code and downloads. GitHub handles activity on its services under the GitHub General Privacy Statement.
