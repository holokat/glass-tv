# Glass TV

Native TV launcher and macOS photo companion. Visual reference: user-supplied sunset landscape launcher,19October2026. Full-bleed landscape; real local clock upper left and Settings upper right; only Netflix and Nintendo Switch app buttons lower left. Focus must be unmistakable from a sofa: bright thin outline, restrained1.06scale and a small visible label beneath selected button. Large remote targets. No content feeds, advertisements, recommendations, account prompts, or fake status.

Muted white controls, thin clock, capsule glass surfaces with translucent dark fill, subtle top highlight and edge. Avoid expensive full-screen real-time blur or continuous motion. Background crossfade only; pause timers and release large image work while not visible. Bundle the generated clean landscape derived from the supplied reference; document it as generated art, not a real location photo. User photos are stored locally.

Mac companion: use the real edge-to-edge macOS window with its standard title bar, traffic lights, toolbar, and `NavigationSplitView` sidebar. Do not draw a faux application window, an inset shell, custom traffic-light controls, or a wallpaper backdrop. The sidebar is a native `.sidebar` `List` with native selection. The window background is AppKit `NSVisualEffectView` using `.underWindowBackground` and `.behindWindow`; custom panels use SwiftUI `.glassEffect(.regular)` and native `.buttonStyle(.glass)` on macOS 26+, with a material fallback on macOS 13–25. Use the system accent for selection and toggles; secondary glass actions retain the neutral system treatment without a global tint override.

Media uses an aligned page header with one native glass Add media button, a leading native segmented filter, and an adaptive AppKit `NSCollectionView` of real local thumbnails. The gallery uses three, two, or one columns with consistent 14-point gaps. Artwork has rounded clipping, actual filenames, rotation state, and video duration. Check controls select items independently of rotation inclusion. Native click, Command-click, Shift-click ranges, Command-A, Escape, and blank-space drag selection support batch work. The bottom native glass action bar appears only with a nonempty selection, with explicit Include in rotation and Remove from rotation actions. The TV inspector uses the supplied Sony frame with actual local media, aligned native playback controls, a connection disclosure, and a persistent Start slideshow button. Its content scrolls independently when needed. Drag-and-drop imports; context menus reorder or include/remove items from rotation without deleting retained local files. Pairing remains available from the dedicated TV page and follows address, certificate fingerprint confirmation, then six-digit code. Only an authenticated status produces a connected state.

Weather uses the same native sidebar and a responsive two-column content layout that vertically scrolls when the window is compact. It begins disabled with no locations. Search, locations, enabled states, selection, removal, reordering, style, unit, forecast visibility, and cycle controls are functional. Forecast data and the TV widget preview use only Open-Meteo data; destination imagery is explicitly labeled AI-generated artwork, not live weather imagery. Landscapes are restricted to the TV media preview and the selected scenic weather-widget style. Credit forecast data in Settings, not in the TV widget preview. All mac UI glyphs use supplied Central exports; use text only where an asset is unavailable.

Movies is one native sidebar destination. It starts with an actual folder picker and presents only recursively scanned video files that ffprobe can read from that security-scoped folder. Search covers locally known title/year and verified metadata genres/cast. Cards show sidecar art, a cached verified metadata poster, an actual extracted frame, or the Central Movies icon in that order. Continue watching appears only for persisted receiver playback progress. No recommendation rows, semantic search claims, invented movie details, or scenic application backdrop. Playback and pause, resume, seek, and stop controls reflect the receiver status; a file can be played only after its secure local stream is established. A file already in the TV profile streams directly; otherwise the app shows preparation progress while it creates a cached 4K H.264/AAC MP4 and leaves the original untouched.

Use licensed Central Icons round outlined radius2 stroke1.5 SVG exports for interface icons. Netflix and Nintendo Switch marks use the supplied official white vector-derived assets in `shared/brands/`; do not substitute Central brand marks. Keep icon styles consistent. No emoji icons. Use system native typography on Android and macOS.


Weather destination artwork lives in `mac/Resources/weather-artwork/` and is bundled offline. The shared catalog contains 50 destinations with five distinct generated scenes each, for 250 JPEGs at native 1672 × 940 or 941 pixels. Location rows, style thumbnails and scenic widget previews use the selected scene; no destination artwork is used as an app-shell background. `WeatherArtwork` resolves stable GeoNames IDs or normalized names together with coordinate bounds, so homonymous locations cannot receive an unrelated landmark image. Unmatched locations retain a neutral fallback. Do not auto-add cities or enable Weather when installing artwork. Forecast temperatures, conditions and times remain real provider data, with explicit disabled, unavailable and loading states. Image-generation prompts and source paths are recorded in the adjacent `provenance.json`.


The TV tab uses the same native sidebar, 30-point semibold page title, 15-point secondary introduction, and 28-point content margins as Media/Weather. The native glass status panel is separate from the shared connection actions and optional address disclosure; the adjacent preview reuses the Sony frame with selected local media. Apple glass/button styles and native text fields, ProgressView and DisclosureGroup provide all control surfaces. No app backdrop image or hand-drawn glass is permitted.

Connection presentation is typed: unpaired, disconnected, checking, certificate discovery, awaiting code, pairing, connected. Unrelated imports do not masquerade as a connection check. Green requires saved pairing and authenticated receiver status; network failures clear the cached success. Certificate/code stages take priority over cached status. The shared app container performs a read-only authenticated status check every 20 seconds while active, avoids concurrent work, and suspends checks when backgrounded or manually disconnected. Re-pairing retains the saved credential until a replacement has been accepted and saved. The preview describes local media rather than claiming a live TV feed.

Weather and TV use balanced 50/50 columns with the same outer margins and column gap. Weather exposes Minimal, Compact, Scenic and Icon & temperature. Minimal has a location header, large current reading, condition, a separate high/low line and an optional five-day forecast. Compact uses the same current reading with condition and high/low on one line and no forecast. Scenic uses bounded 16:9 destination artwork with city and temperature above, condition lower left, and high/low plus the observation timestamp lower right. All four share native Apple controls on Mac; Icon & temperature has no widget surface. Older `detailed` settings migrate to `minimal`; the saved hourly flag is retained for compatibility without an hourly strip.

TV address editing uses a local draft committed with Return or Use address, so typing does not replace the field or reload pairing mid-edit. Automatic connection checks pause while address details are open or a draft is pending.

The Media inspector has a native Show TV interface switch, enabled by default for existing libraries. It controls the TV clock, shortcuts, Settings and weather as a group during ambient media playback. Hidden mode must preserve the media layers and weather preferences. Remote navigation reveals overlays temporarily without also activating a shortcut; active interaction renews the reveal interval. Paused playback and open settings dialogs keep controls accessible. Movie playback retains its existing independent controls. The TV clock uses larger type and bounds that accommodate the complete time, including AM/PM.

Connection-dependent actions share one verified-state policy. Saved pairing alone never enables playback or implies a live connection. Offline Media shows Connect; Disconnect is offered only for an authenticated connection. Start slideshow is disabled while disconnected, connecting, pairing or busy. Local browsing, selection, import and settings editing remain available offline. Disconnect is a local connection action that retains pairing; automatic checks must respect that explicit choice until Connect is chosen.


## Native macOS design system

`mac/DesignSystem.swift` is the implementation source for shared presentation. Read this guide before adding or changing a screen. Reuse its components and modifiers; update the shared implementation when a rule changes.

| Element | Rule |
| --- | --- |
| Page heading | Use `PageHeading`. Media, Movies, TV, Weather and Settings use 30-point semibold system type. Optional introductions use 15-point secondary text with a 6-point gap. |
| Action buttons | Use `nativeGlassButton()` everywhere: Apple's `.glass`, regular control size (small for compact poster icon actions), native rounded-rectangle border shape with an 8-point radius. Older systems use Apple's bordered fallback. Do not introduce capsule, prominent, custom-painted or per-screen action styles. |
| Button labels | Sentence case; Central outlined icon before the label, typically 17 points with an 8-point gap. Icon-only actions need an accessibility label or help text. |
| Compact interaction affordances | Use icons for familiar mechanical controls such as drag grips, resize handles, refresh, close and carousel arrows. Do not show instruction words such as “Drag” on the control or repeat them as persistent helper copy. Use the existing Central icon variant, a concise tooltip and an accessible action name. Keep text for choices or actions whose meaning would otherwise be ambiguous. |
| Selection controls | Native sidebar selection, segmented pickers, switches and checkboxes retain their platform behavior. Artwork tiles may have plain hit targets; these are selection/content surfaces, not alternate action-button designs. |
| System dialogs and menus | Keep macOS file pickers, alerts and menu items native. Do not repaint their controls to imitate in-content buttons. |
| Layout | 28-point horizontal page inset, 24-point top inset, approximately 20 points between content sections, 24-point columns. Keep related labels and controls together and use consistent leading alignment. |
| Glass surfaces | Reuse `nativeGlass` and `nativeGlassGroup`, backed by Apple's glass APIs. No faux glass, wallpaper behind the Mac app, manual shadows or custom window chrome. |
| States | Derive enabled state from the shared verified connection policy. Local browsing and selection remain available offline. Do not replace native disabled, focus, hover or pressed rendering. |

Before shipping a UI change, inspect the actual app for heading alignment, sentence case, spacing, truncation, consistent button shape and disabled-state correctness. New screens must use the shared sidebar, heading and action-button modifier.

API references: [Apple glass button style](https://developer.apple.com/documentation/swiftui/primitivebuttonstyle/glass) and [native button border shape](https://developer.apple.com/documentation/swiftui/view/buttonbordershape(_:)).

Favorites retains every favorited movie, including watched favorites. Watched contains movies manually marked watched. Search applies within the selected collection. They remain separately focusable, accessible, and available offline when playback is disabled; selected states use the system accent. Controls are fully hidden until the poster is hovered or an action receives keyboard focus, including when favorited or watched. Hidden controls do not intercept pointer clicks. Selecting a different library resets its organization with the existing folder-switch behavior. Empty collection messages explain how to add or restore movies without fabricated content.

## Standalone TV settings

Apps and Weather must be usable on the TV without pairing a Mac. Use large, readable system typography, dark neutral grouped surfaces, generous row spacing and an unmistakable white focus outline. Carry over the companion's hierarchy and concise labels, adapting controls to directional navigation and OK/Back. Do not reproduce desktop drag handles or rely on pointer hover.

Use explicit choices for style and units, focusable controls for numeric adjustments, and move-up/move-down actions for ordering. Keep city and app management separate from appearance settings. City search must distinguish loading, no results and network failure; retain country or region in search results for disambiguation while widget headings remain city-only. Preserve native TV input, system settings and Mac pairing access.

Changes save on the receiver and refresh the launcher. The Mac is an optional editor, not a prerequisite for these controls. Reconnection must reconcile current receiver preferences with pending companion edits and preserve unrelated media, pairing and layout drafts.
